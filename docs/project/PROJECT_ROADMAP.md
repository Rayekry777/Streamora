## 推进规则

- 每个阶段依次执行：契约、后端主链路、用户端与管理端、联调、验收。
- 后端契约领先半步；前端可以使用同形 Mock 并行开发，联调时必须替换 Mock。
- 阶段出口条件全部有证据后标记“待验收”；只有用户明确通过后标记“已完成”。
- 当前阶段未完成时不主动开始下一阶段。

## MVP 边界

第一版不包含直播、支付、原生 App、实时语音、多宠物和运行时生成 Live2D 服装。正式 Live2D 模型由项目方后续提供；阶段 1–5 使用合法占位资源和 `PetRenderer` 降级实现。
