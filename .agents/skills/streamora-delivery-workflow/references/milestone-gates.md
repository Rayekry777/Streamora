# 里程碑门禁

## 通用门禁

每个阶段依次通过以下门禁：

1. **契约**：接口、事件、权限、数据归属和失败语义已确定。
2. **后端**：主成功路径可运行，迁移、日志、OpenAPI 和测试同步完成。
3. **前端**：用户端与管理端按契约完成本阶段页面；Mock 仅用于未接通前。
4. **联调**：真实接口替换 Mock，关键链路、异常路径和权限共同验证。
5. **验收**：出口条件有证据，剩余风险明确，状态改为“待验收”。

## 阶段出口

| 阶段 | 出口条件 |
|---|---|
| 0 | 三套 Skill 校验通过；17 个服务职责、数据边界、接口和事件契约无冲突 |
| 1 | 两个前端和 17 个运行单元可构建；基础设施配置可验证；健康检查齐全 |
| 2 | 用户和管理会话隔离；RBAC 与公共宠物到个人宠物切换通过 |
| 3 | 一个视频完成分片上传、转码、审核、发布和 HLS 播放 |
| 4 | 弹幕、评论、互动、举报和审核形成闭环 |
| 5 | 宠物跨路由不重建，在播放器全屏中可见且不阻塞主要操作 |
| 6 | Agent 流式对话、记忆与语义反应可用；写操作未经确认不能执行 |
| 7 | 推荐、搜索、通知与运营仪表盘形成闭环 |
| 8 | 功能、权限、性能、安全、幂等和故障恢复验收通过 |
