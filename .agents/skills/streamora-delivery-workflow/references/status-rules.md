# 状态规则

## 允许的阶段状态

- `未开始`：尚未执行该阶段。
- `进行中`：正在实现，出口条件未全部满足。
- `待验收`：实现和内部验证完成，等待用户验收。
- `已完成`：用户明确验收通过。
- `受阻`：存在不能在当前权限或上下文内解除的外部阻塞。

## 转换规则

- `未开始 -> 进行中`：开始执行当前阶段。
- `进行中 -> 待验收`：所有出口条件有可核查证据。
- `待验收 -> 已完成`：仅由用户确认触发。
- `待验收 -> 进行中`：用户提出验收问题或发现回归。
- 禁止从 `未开始` 直接进入 `已完成`。
- 当前阶段未完成时，后续阶段保持 `未开始`。

代码能力状态沿用 `docs/development/BACKEND_DEVELOPMENT.md` 的“未确认、未实现、开发中、已实现、已废弃”，不得与阶段状态混用。
