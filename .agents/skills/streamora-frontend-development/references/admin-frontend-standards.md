# 管理端规范

- 管理端桌面优先，不加载 Live2D、宠物 Store、宠物 SSE 或用户会话模块。
- 路由和操作按钮同时检查权限，但以后端权限结果为最终依据。
- 内置角色：`SUPER_ADMIN`、`CONTENT_MODERATOR`、`USER_OPERATOR`、`AI_OPERATOR`、`SYSTEM_OPERATOR`。
- 高风险操作界面必须展示影响摘要并收集原因；密码复验后取得五分钟、一次性、动作作用域令牌。
- 批量任务异步执行，显示进度、部分失败和可导出结果；禁止用长时间阻塞请求伪装批处理。
- 审计页不提供编辑和删除入口；敏感字段只显示脱敏值。
- 内容、用户、媒体、宠物资产、提示词、模型路由均提供版本或操作历史及可回滚入口。
